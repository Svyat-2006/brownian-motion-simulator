Симулятор броуновского движения и идеального газа
Высокопроизводительное десктопное приложение для симуляции броуновского движения и статистической физики идеального газа. Проект построен на связке Tauri (Rust) и React + Three.js. Физический движок вынесен в отдельный Web Worker, что позволяет плавно отрисовывать и просчитывать столкновения до 10 000 частиц при 60 FPS, используя пространственное хеширование (Spatial Hash Grid).

🚀 Основные возможности
Реалистичная физика: Упругие столкновения, динамическое изменение температуры, распределение скоростей Максвелла-Больцмана.

Смена размерности: Моделирование в 3D (сфера), 2D (цилиндр) и 1D (поршень) с автоматическим перераспределением степеней свободы и энергии.

Глубокая аналитика: Графики реального времени (Chart.js) для кинетической энергии по осям и гистограммы скоростей. Поддержка зума, панорамирования и полноэкранного режима.

Интерактивность: Спавн частиц по клику в 3D-пространстве (Raycasting), управление массой, температурой и количеством молекул «на лету».

Мультиязычность (i18n): Полная поддержка русского и английского языков.

📂 Структура проекта (Назначение файлов)
Проект разделен на логические модули для удобства поддержки и масштабирования. Основной код интерфейса и физики находится в папке src/.

⚛️ Интерфейс и логика (React)
src/App.tsx — Главный файл приложения. Отвечает за маршрутизацию вкладок («Симулятор» / «Теория»), хранение глобальных состояний (температура, масса, размерность) и дросселирование (throttling) обновлений для графиков, чтобы интерфейс не зависал.

src/i18n.ts — Конфигурация локализации (i18next). Содержит JSON-словари со всеми текстами приложения на русском и английском языках.

src/Theory.tsx — Статический компонент с подробным описанием физической модели, теоремы о равнораспределении энергии и формул.

🎮 3D-Рендеринг (Three.js)
src/Scene.tsx — Конфигурация 3D-сцены. Настраивает освещение, камеру (OrbitControls) и отрисовывает центральный броуновский объект (Сфера, Цилиндр или Куб) в зависимости от выбранной размерности.

src/Particles.tsx — Отвечает за рендер малых молекул газа. Использует THREE.InstancedMesh для отрисовки до 10 000 частиц за один вызов видеокарты (Draw Call). Также здесь инициализируется Web Worker и работает система Raycasting для добавления частиц по клику мыши.

⚙️ Физический движок (Web Worker)
src/physics/worker.ts — Сердце симулятора. Работает в отдельном фоновом потоке, не блокируя UI. Выполняет:

Управление плоскими массивами памяти (Float32Array) для координат и скоростей.

Пространственное хеширование (Spatial Hash Grid) для снижения сложности поиска столкновений с O(N 
2
 ) до O(N).

Расчет упругих столкновений молекул друг с другом и с центральным объектом.

Сбор аналитики (кинетическая энергия и распределение скоростей) для отправки обратно в React.

📊 Аналитика
src/Charts.tsx — Компонент графиков на базе react-chartjs-2. Отрисовывает линейный график истории энергии и гистограмму скоростей. Включает логику для модальных окон (раскрытие на весь экран) и интеграцию плагина для масштабирования (Zoom/Pan).

🖥 Backend (Tauri)
src-tauri/ — Папка, сгенерированная фреймворком Tauri. Содержит конфигурацию сборки (tauri.conf.json), настройки прав окон и базовый код на Rust для создания нативного десктопного окна и взаимодействия с операционной системой.

💻 Как запустить проект локально
Чтобы развернуть проект на своем компьютере, вам понадобятся установленные среды Node.js и Rust (необходимы для работы Tauri).

Шаг 1. Клонирование репозитория
Откройте терминал и выполните команду для скачивания кода:

```Bash
git clone https://github.com/Svyat-2006/brownian-motion-simulator.git
```
Перейдите в папку проекта:

```Bash
cd brownian-motion-simulator
```
Шаг 2. Установка зависимостей
Установите все необходимые npm-пакеты (React, Three.js, Chart.js и другие):

```Bash
npm install
```
Шаг 3. Запуск в режиме разработчика
Запустите проект с помощью CLI-инструмента Tauri. При первом запуске Rust скачает и скомпилирует backend-зависимости (это может занять несколько минут):

```Bash
npm run tauri dev
```
После успешной сборки откроется нативное десктопное окно с симулятором.

Шаг 4. Сборка для релиза (опционально)
Чтобы создать готовый .exe файл (или .app/.deb в зависимости от вашей ОС), выполните:

```Bash
npm run tauri build
```
Готовый установщик и бинарный файл будут находиться в папке src-tauri/target/release/bundle/.
